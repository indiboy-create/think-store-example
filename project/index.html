youvision/think-store-example

Think Store Example：静态部署与随机诗接口示例

这是一个 ThinkPHP 8 示例包，演示 think-static 静态资源部署、layui 页面构建和基于路由的随机抽诗接口。

查看项目介绍 查看示例详情

static 静态资源部署

youvision/think-static 将 project 目录发布到 public/store/store-example，包含 layui 主题、视图与示例页面。

部署路径 /store/store-example

api 随机诗接口

从 data/300.json 的 319 首唐诗中随机抽取一首，通过 GET /poems/random 返回 JSON 数据。

路由 /poems/random

layui layui 页面

页面使用 project/theme/layui 构建，layui 目录保持原样，自定义样式统一写入 theme/css/index.css。

layui 2.9 · 响应式布局

example 示例结构

config 提供接口配置，route 定义路由，src 包含控制器与诗库读取逻辑，project 为静态资源目录。

PHP >= 8.0 · ThinkPHP 8
