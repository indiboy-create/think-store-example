think-static

ThinkPHP 8 项目部署插件。主项目安装或更新依赖时，自动把 project 目录部署到 public/store。

安装
composer require youvision/think-static

Composer 2.2 及以上版本需要在主项目 composer.json 中允许插件 youvision/think-static。

版本信息
字段 值
包名 youvision/think-static
类型 composer-plugin
PHP >= 8.0
ThinkPHP 8.x
部署目标 public/store/store-example
相关文件
  • ../view/index.html：应用卡片模板片段。
  • ../extend/demo.php：应用元数据示例。
  • ../theme/css/index.css：项目自定义样式。
