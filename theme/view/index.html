youvision/think-store-example

包内视图、资源路由与随机诗接口，一次看懂

面向 ThinkPHP 8 的示例发布包：页面由包内 think-view 渲染，layui 资源经 assets 路由输出，无需发布到 public；随机抽诗接口演示路由注册与 JSON 响应。

体验随机抽诗 了解实现方式

  • {$poemCount}首唐诗
  • 5个示例页面
  • 1个 JSON 接口
  • 0public 发布
01 · Capabilities

包内自带的能力

视图、资源、接口与页面样式都随包提供，宿主项目只需安装依赖并访问路由。

01
包内视图渲染

theme/view 下的模板由包内 View 渲染器通过 think-view 直接输出，主项目不需要复制视图文件。

topthink/think-view · 缓存前缀 store_example_
02
包内静态资源

layui 与自定义样式由 assets 路由直接读取 theme/assets 输出，路径经过 realpath 校验并拒绝目录穿越。

{$assets}/<path> · 缓存 1 天
03
随机抽诗接口

从 data/300.json 的 {$poemCount} 首唐诗中随机抽取一首，通过随机抽诗路由返回 JSON 数据。

GET {$api}
04
layui 页面

页面沿用 layui 组件与现有配色，自定义样式集中在 theme/assets/css/index.css，并适配移动端。

layui 2.13.9 · 响应式布局
02 · Quick start

三步查看示例

安装为依赖后，路由、视图与静态资源全部由包内提供，不需要修改主项目目录。

  1. 01 安装包 composer require youvision/think-store-example
  2. 02 访问首页 {$home}
  3. 03 打开示例 唐诗页 {$base}/poems，接口 {$api}
