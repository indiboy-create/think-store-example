youvision/think-store-example

Think Store Example：包内视图与随机诗接口示例

面向 ThinkPHP 8 的示例发布包：页面由包内 think-view 渲染，layui 资源由 assets 路由输出，无需发布到 public；同时提供基于路由的随机抽诗接口。

查看项目介绍 打开唐诗示例

view 包内视图渲染

theme/view 下的模板由包内 View 渲染器通过 think-view 直接输出，主项目不需要复制视图文件。

topthink/think-view · 缓存前缀 store_example_

assets 包内静态资源

layui 与自定义样式由 assets 路由直接读取 theme/assets 输出，路径经过 realpath 校验并拒绝目录穿越。

{$assets}/<path> · 缓存 1 天

api 随机抽诗接口

从 data/300.json 的 {$poemCount} 首唐诗中随机抽取一首，通过随机抽诗路由返回 JSON 数据。

GET {$api}

layui layui 页面

页面沿用 layui 组件与现有配色，自定义样式集中在 theme/assets/css/index.css，并适配移动端。

layui 2.13.9 · 响应式布局

Quick start

三步查看示例

安装为依赖后，路由、视图与静态资源全部由包内提供，不需要修改主项目目录。

  1. 01安装包：composer require youvision/think-store-example
  2. 02访问首页：{$base}
  3. 03打开唐诗示例：{$base}/poems，接口为 {$api}
