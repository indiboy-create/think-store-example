实例说明

这个包如何被安装与渲染

Think Store Example 只作为依赖安装到已有 ThinkPHP 8 项目。服务启动时合并配置并加载路由，页面由包内视图渲染，静态资源通过 assets 路由输出。

Composer composer require youvision/think-store-example
01 · Overview

包信息与目录结构

安装后由服务注册路由、合并配置，并固定从包内 theme/view 读取模板。

包信息 meta
{volist name="meta" id="item"} {/volist}
{$item.label} {$item.value}
目录职责 tree
  • theme/view/ 包内模板，由 View 渲染器固定从该目录读取。
  • theme/assets/ layui、样式与页面脚本，通过 assets 路由输出。
  • config/store_example.php 路由与诗库配置，可与主项目配置合并。
  • route/store_example.php 页面、随机抽诗接口与静态资源路由。
  • src/ 服务注册、视图渲染、资源输出、页面控制与诗库读取。
  • data/300.json 诗库数据，共 {$poemCount} 首。
02 · How it works

路由、资源与配置合并

从服务启动到页面输出，整个链路由包内代码完成，主项目只需要维护配置。

  • 01路由与资源
  • 02配置合并
  1. 01
    加载路由

    Service::boot() 在 route.enabled 为真时加载 route/store_example.php。

  2. 02
    渲染页面

    页面路由指向 StoreExampleController，由 View 渲染 theme/view 下的模板。

  3. 03
    推导地址

    页面、接口与资源地址由 StoreExample 根据 route.prefix、route.segment 与 assets 推导，避免硬编码。

  4. 04
    输出资源

    assets 路由读取 theme/assets，经 realpath 校验后输出并附加 1 天缓存。

  5. 05
    返回数据

    接口路由指向 PoemController，从诗库随机返回一首诗。

包内默认配置与主项目 config/store_example.php 使用 array_replace_recursive 合并，项目侧优先；修改后清除 runtime 缓存即可生效。

配置项 默认值 说明
route.enabled true 是否注册页面、接口与静态资源路由。
route.prefix store 路由前缀，留空时页面地址变为 /think-store-example/index。
route.segment think-store-example 包内命名空间，留空时页面直接挂在路由前缀下。
route.middleware [] 应用到整组路由的中间件，可填写类名或别名。
assets assets 相对路径拼在命名空间后，以 / 开头时视为绝对地址。
data_file 空字符串 自定义诗库 JSON；留空时使用包内 data/300.json。
