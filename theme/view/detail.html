安装与配置 config
Composer composer require youvision/think-store-example
配置项 默认值 说明
route.enabled true 是否注册页面、随机抽诗接口与静态资源路由。
route.prefix store 路由前缀，留空时页面地址变为 /think-store-example/index。
route.segment think-store-example 包内命名空间，留空时页面直接挂在路由前缀下。
route.middleware [] 应用到整组路由的中间件，可填写类名或别名。
assets assets 静态资源地址，相对路径拼在命名空间后，以 / 开头时视为绝对地址。
data_file 空字符串 自定义诗库 JSON 的绝对路径；留空时使用包内 data/300.json。

包内默认配置会与主项目配置合并，项目侧优先；修改后清除 runtime 缓存即可生效。
